# patient-management-system

A console-based Patient Management System built in C++ that allows users to manage patient records efficiently. This project demonstrates object-oriented programming, data management using vectors, and user input handling.



## Description
This application allows users to add, view, search, and delete patient records through a simple terminal interface. It was developed to practice core C++ concepts such as classes, file structure organization, and modular programming.


## Features
- Add new patient records  
- View all patients  
- Search patients by ID  
- Delete patient records  
- Input validation for smoother user experience
